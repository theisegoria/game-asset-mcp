# Support

Use [GitHub Issues](https://github.com/theisegoria/game-development-studio-macos/issues)
for installation questions, reproducible defects, feature requests, and
documentation problems.

Before filing:

1. record the app version and macOS version;
2. run `game-dev --version` and `game-dev doctor --json` when the CLI starts;
3. state whether the app's CLI path is `game-dev` from `PATH` or an explicit
   executable;
4. state whether Blender or a project adapter was involved; and
5. remove credentials, signed URLs, private paths, private source, logs with
   sensitive content, and paid provider assets from the report.

For the current ad-hoc, non-notarized release, include the exact Gatekeeper or
signature error if the app does not open. Do not disable Gatekeeper globally.

Use [GitHub private vulnerability reporting](https://github.com/theisegoria/game-development-studio-macos/security/advisories/new)
for a security-sensitive issue. Provider billing, account, policy, or service
availability questions belong with the provider.
